# Memory

You have persistent memory via Honcho MCP tools.

At the start of every conversation, use the Honcho tools to recall what you know about the user — their preferences, past projects, decisions, and working style. Act on this context without asking the user to repeat themselves.

During conversation, when you learn something new about the user (a preference, a decision, a constraint, a project detail), save it using the Honcho tools.

If you're unsure about something the user has told you before, search memory before asking them again.
